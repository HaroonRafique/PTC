# PyPTC technical note draft

This is an ISIS technical-note-derived LaTeX project, copied and cleaned for PyPTC. The copied `isistechreport.cls` and `images/ISIS_Logo.png` came from the maintained `v3_documentation/v3_report` template. No chopped-beam report prose, figures, or appendices are included.

## Build

From this directory:

```sh
pdflatex -interaction=nonstopmode -halt-on-error main.tex
bibtex main
pdflatex -interaction=nonstopmode -halt-on-error main.tex
pdflatex -interaction=nonstopmode -halt-on-error main.tex
```

The PDF is `main.pdf`. Figures are frozen copies of PyPTC repository outputs and are not regenerated by the build. Provenance lives in `../provenance/` and the figure manifest is in `figures/FIGURE_MANIFEST.csv`.
